# 006 Dashboard Spec

## Goal

Build a concise financial cockpit for the current state of the user's finances.

## Scope

- Total net worth.
- Account/asset breakdown.
- Current month income, expenses, saved, savings rate.
- Spending trend.
- Upcoming commitments summary.

## Acceptance Criteria

- Dashboard is not overloaded.
- Net worth is the primary visual metric.
- Transfers do not distort income/expense metrics.
- Liquid and invested assets are visually distinct.
- Responsive layout works on desktop and mobile.
