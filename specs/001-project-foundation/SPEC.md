# 001 Project Foundation Spec

## Goal

Create the initial Next.js application foundation and development toolchain without implementing finance features.

## Scope

- Next.js app router with TypeScript.
- Tailwind CSS and shadcn/ui setup.
- Base app shell placeholder.
- Supabase client wiring.
- Vitest and Playwright setup.
- Initial linting and formatting commands.
- Environment variable documentation.

## Acceptance Criteria

- The app runs locally.
- TypeScript checks pass.
- A placeholder authenticated-app layout can be developed in later phases.
- Test commands exist and pass with at least one smoke test.
- `.env.example` includes required Supabase variables and no secrets.
