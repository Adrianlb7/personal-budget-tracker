# 016 Visual System and Appearance

## Goal

Refresh Orba's visual language with a restrained, Apple-inspired finish and a usable light/dark appearance setting.

## Scope

- Calm surfaces, clear hierarchy, refined navigation and consistent interactive states across desktop and mobile.
- Light, dark and system appearance modes, persisted locally and applied before the page paints.
- Accessible controls and sufficient contrast for financial values, forms, charts, menus and dialogs.
- Preserve the liquid dashboard signature, existing financial behavior, and PWA data-caching rules.

## Acceptance Criteria

- Users can change appearance without signing out or reloading.
- Choice persists across navigation and reload; system mode follows OS changes.
- Public, authenticated and offline screens are readable in both themes.
- Visual changes do not affect stored financial data or calculations.
